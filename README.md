# Pokémon App
This is a Vue.js application that displays a list of Pokémon using the PokéAPI. Users can view Pokémon details, search by name, and edit information. The app uses **Pinia** for state management and features a responsive UI with some interactive animations.

---

### How to Run This App Locally
Follow the steps below to set up and run the app on your computer.

### 1. Install Node.js

Make sure you have **Node.js** and **npm** installed.

Download Node.js: https://nodejs.org/

To check if they’re installed, run:

```bash
node -v
npm -v
---

#### 2. Install Vue CLI (if not already installed)
npm install -g @vue/cli

### 3. Clone or Download This Project
Using Git:
git clone https://github.com/your-username/pokemon-app.git
cd pokemon-app
Or download the ZIP file, extract it, and open the folder in your terminal.

### 4. Install Dependencies
npm install

### 5. Run the App in Development Mode
npm run serve

###6. Once it’s running, open your browser and go to:
http://localhost:8080

You should now see the Pokémon app running locally!
